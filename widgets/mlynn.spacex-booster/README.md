# Next SpaceX launch

The next SpaceX launch: mission, rocket, time (in the TV's time zone) and status, then each booster flying it with its serial, which flight this is for it, and its landing site (drone ship or landing zone). The footer shows the rocket family's run of consecutive landings and the launch site.

Data: Launch Library 2, `ll.thespacedevs.com` (free, no key; the free tier allows 15 requests an hour, so it refreshes hourly).

Screenshot is a mock-up rendered from live data, not a TV capture.
